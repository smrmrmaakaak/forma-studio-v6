# FORMA STUDIO v6 — 하이엔드 웹 디자인 에셋 아틀리에 & 풀페이지 조립 스튜디오

**26개 모듈 슬롯 × 총 252종 실작동 라이브 에셋**을 조합하여, 단품 UI 에셋 확인·단독 코드 추출부터 클라이언트 미팅용 완성 홈페이지 시안 비교(`시안 A / B / C`)까지 한 곳에서 수행하는 모듈형 웹 디자인 스튜디오입니다.

## 주요 구성

- **단품 에셋 아틀리에 (13개 슬롯 · 134종)**
  - `01` 컬러 시스템 (12) · `02` 60fps 캔버스 배경 셰이더 (10) · `03` 내장 한글·영문 서체 (8)
  - `04` 키네틱 타이포그래피 (10) · `05` 피직스 버튼 (16) · `06` 스포트라이트·3D 카드 (12)
  - `07` 사진 마스크·필름 그레이딩 (10) · `08` 인풋·토글·스테퍼·슬라이더 (10) · `09` 커스텀 마우스 커서·스타더스트 입자 (8)
  - `10` 스크롤·등장 모션 (10) · `11` 에디토리얼 배지 (10) · `12` 인트로 커튼·스크롤 게이지 (8) · `13` 플로팅 독·Web Audio 사운드 위젯 (10)
- **풀페이지 섹션 아키텍처 (13개 슬롯 · 118종)**
  - `14` 상단 어나운스 바 (8) · `15` 네비게이션 헤더 (8) · `16` 히어로 아키텍처 (10) · `17` 마키·디바이더 (8)
  - `18` 실적·카운터 지표 (8) · `19` 벤토·인터랙티브 탭 (8) · `20` 프로세스·타임라인 (10) · `21` 룩북·포트폴리오 (10)
  - `22` 팀·디렉터·장인 소개 (10) · `23` 요금제·멤버십 (10) · `24` 고객리뷰·FAQ (10) · `25` 컨시어지 예약·견적 폼 (10) · `26` 모뉴멘탈 푸터 (8)

## 실행 및 빌드 구조

- **`index.html`**: 한글·영문 웹폰트(`.woff2` 11종)와 고해상도 에디토리얼 이미지 10장이 모두 내장된 무설치 단일 실행 파일 (크롬 브라우저 또는 GitHub Pages에서 즉시 실행).
- **`v6/`**: 유지보수 및 확장을 위한 모듈형 원본 소스 코드
  - `v6/01_styles.css` — 디자인 토큰, 서체, 버튼·카드·인풋·모션 스타일시트
  - `v6/02_worlds_and_assets.js` — 6대 업종 월드 프리셋 및 134종 단품 에셋 정의
  - `v6/03_sections_a.js`, `v6/03_sections_b.js` — 118종 풀페이지 섹션 템플릿
  - `v6/04_engine_and_ui.js` — 스튜디오 상태 엔진, 60fps 셰이더, 시안 A/B/C 비교 및 단독 실행 코드 추출기
  - `v6/build_v6.py` — 단일 배포 번들(`index.html`) 컴파일 스크립트
